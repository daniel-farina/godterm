# homebrew-godterm

Homebrew tap for [GodTerm](https://github.com/daniel-farina/godterm): run many
Claude Code (and Grok) sessions side by side, each on its own account.

```sh
brew install --cask daniel-farina/godterm/godterm   # GodTerm.app (macOS)
brew install daniel-farina/godterm/godterm          # just the godterm command (macOS, Linux)
```

The formula and cask are generated by `scripts/release/homebrew.sh` in
daniel-farina/godterm for each release; do not edit them here.
